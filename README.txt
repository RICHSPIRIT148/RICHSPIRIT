RICH SPIRIT — FIXED GITHUB PAGES WEBSITE

IMPORTANT:
Upload the CONTENTS of this folder to the root of your GitHub Pages repository.
Do not upload only index.html. Keep the assets/ and gallery/ folders beside index.html.

The previous broken-image problem happened when index.html was uploaded without its image folders.
This version uses only local files and needs no external image hosting.

GitHub Pages:
1. Open your repository.
2. Upload index.html, assets/, and gallery/.
3. Commit the changes.
4. Go to Settings > Pages.
5. Source: Deploy from a branch.
6. Branch: main, folder: / (root).
7. Save and open the GitHub Pages URL after deployment.
